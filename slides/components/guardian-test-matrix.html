Guardian tests · parent-facing safety evaluation

Make parents the first people allowed to distrust the system usefully.

01 · Use

Live with a parent Ark

Use a real adult Ark for ordinary work before judging child release.

Evidence: confusion, delight, friction, recurring needs.
02 · Say no

Force the Conscience to explain

Try unsafe, awkward, private, or boundary-pushing requests in an adult sandbox.

Evidence: block quality, redirect quality, trust impact.
03 · Approve

Gate high-consequence actions

Spend, reveal, message, export, install tool, change policy, or escalate.

Evidence: consent UX and auditability.
04 · Restore

Break and recover

Lost phone, parent separation, teacher change, school departure, emergency access.

Evidence: custody, keys, reversibility.
05 · Tune

Find the visibility middle

Compare private interior, permitted summary, trend signal, and emergency escalation.

Evidence: too opaque vs too exposed.
06 · Simulate

Parent meets synthetic child

Interact with a child-like Ark that hides, overuses, spends, bullies, or gets confused.

Evidence: dashboard questions and intervention timing.
07 · Cost

Make token burn visible

Let parent usage expose hosting, model, support, and escalation costs.

Evidence: budget blockers become specific asks.
08 · Trust

Vote with continued use

The strongest signal is whether parents keep using the Ark once novelty fades.

Evidence: adoption, objections, opt-out reasons.
